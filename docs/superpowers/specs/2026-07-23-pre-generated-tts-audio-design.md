# 预生成神经 TTS 语音升级设计

## 目标

将训练中的主要语音从运行时 Web Speech API 合成升级为随应用发布的本地音频，以获得稳定、自然且一致的普通话播报。训练引擎仍是唯一时间源，现有 `VoiceEvent` 与 `VoiceController` 边界保持不变。

## 已确认范围

- 第一版仅支持普通话中文。
- 使用温和、专业、清晰、自然偏慢的成年女声。
- 音频由付费商用神经 TTS 平台在开发阶段生成，不在用户训练时调用远程服务。
- 首版通过平台控制台手动生成和下载，不新增一次性批量生成脚本。
- 覆盖简洁模式、引导模式、1 至 5 秒倒计时以及训练生命周期提示。
- 不增加后端、运行时 API Key、声音克隆、背景音乐或用户数据上传。

## 素材清单

共准备 18 个独立语音文件。简洁与引导模式可复用暂停、继续和停止等措辞相同的文件。

### 简洁模式

| 文件 | 文案 |
| --- | --- |
| `concise/ready.mp3` | 准备开始 |
| `concise/contract.mp3` | 收紧 |
| `concise/hold.mp3` | 保持 |
| `concise/relax.mp3` | 放松 |
| `common/paused.mp3` | 训练已暂停 |
| `common/resumed.mp3` | 继续训练 |
| `concise/completed.mp3` | 训练完成 |
| `common/stopped.mp3` | 训练已结束 |

### 引导模式

| 文件 | 文案 |
| --- | --- |
| `guided/ready.mp3` | 调整呼吸，准备开始 |
| `guided/contract.mp3` | 轻轻收紧盆底肌，并向上提 |
| `guided/hold.mp3` | 保持张力，继续自然呼吸 |
| `guided/relax.mp3` | 缓慢释放，让肌肉完全放松 |
| `guided/completed.mp3` | 训练完成，保持自然呼吸，让肌肉完全放松 |

### 倒计时

| 文件 | 文案 |
| --- | --- |
| `countdown/1.mp3` | 一 |
| `countdown/2.mp3` | 二 |
| `countdown/3.mp3` | 三 |
| `countdown/4.mp3` | 四 |
| `countdown/5.mp3` | 五 |

轮次播报暂不制作组合音频；界面继续显示轮次。若保留动态轮次朗读，则由浏览器 TTS 作为非关键辅助，不得阻塞固定提示音频。

## 音频规范与授权

- 交付格式为 MP3、单声道、44.1 kHz、64 至 96 kbps。
- 同一音色、语速、音量与合成参数生成全部文件。
- 目标综合响度约为 `-16 LUFS`，避免文件之间出现明显音量跳变。
- 开头静音不超过 100ms，结尾静音不超过 200ms。
- 不添加混响、提示音或背景音乐。
- 每个文件尽量小于 100 KB。
- 所选平台与音色必须允许生成内容随公开网页长期分发；账号和 API Key 不进入仓库。

## 播放架构

新增一个真正播放本地文件的适配器，并继续实现现有 `VoicePlaybackAdapter` 接口。控制器根据事件、模式和阶段解析资源路径，然后交给适配器预加载和播放。`useKegelEngine`、`MuscleSphere` 和训练计时逻辑不感知音频文件。

核心阶段与生命周期提示优先播放本地语音。资源加载或播放失败时跳过当前语音，并降级为已有 Web Audio 提示音；失败不得中断训练或阻塞后续事件。Web Speech API 只保留给未预生成的动态内容或缺失资源，不再作为核心阶段提示的主通道。

## 可靠性规则

- 开始训练或试听的用户手势中预加载或解锁音频播放能力。
- 每次播放设置有限超时；`ended`、`error` 和超时均必须释放当前任务并继续队列。
- 停止与阶段打断必须清理监听器和超时器。
- 单个文件失败后允许后续文件继续播放。
- 已过期的倒计时和上一阶段提示仍按现有队列规则丢弃。
- 不为预加载失败无限重试。

现有 `SpeechSynthesisAdapter` 同样补充超时保护，避免浏览器未派发 `end` 或 `error` 时永久占用 `VoiceController.processing`。

## 测试与验收

自动化测试至少覆盖：

- 资源映射能为简洁、引导和倒计时事件返回正确文件。
- 本地音频正常结束后队列继续处理下一项。
- 音频触发错误或永不结束时，超时后队列仍能继续。
- 阶段切换和停止会中断当前音频并清理监听器。
- 缺失资源会降级到提示音，不影响训练引擎。
- Web Speech API 未触发结束事件时不会永久堵塞队列。

人工验收覆盖 Chrome、Safari 和至少一台移动设备，完整检查开始、阶段切换、倒计时、暂停、继续、停止、完成、静音模式、资源加载失败与锁屏/切后台恢复。音色验收要求语句清楚、无明显机械停顿、各文件响度一致，并且短阶段内不会因为语音过长覆盖下一阶段。

## 非目标

- 不在第一版提供音色选择器。
- 不制作英文音频。
- 不引入运行时云端 TTS 或后端代理。
- 不实现自动音频剪辑、响度标准化流水线或内容管理系统。
- 不修改与语音播放无关的训练视觉与业务逻辑。
