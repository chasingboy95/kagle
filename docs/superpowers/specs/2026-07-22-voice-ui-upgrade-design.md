 # 凯格尔训练 — 语音与交互升级设计

 ## 概述

 基于现有凯格尔训练计时器，重构交互流程：加入开始前倒数、SVG 圆环进度动画、更清晰的状态反馈。

 ## 架构决定

 **SVG `stroke-dasharray` 实现圆环**。轻量、无重绘循环、移动端缩放友好。保持单文件 `index.html` 结构。

 ## 交互流程

 ```
 点击「开始训练」
     │
     ▼
  倒数阶段 (3s)
     │  圆环脉动 + 语音 "3... 2... 1..."
     │  中央显示大字数字
     ▼
  训练循环 (N 组)
     │
     ├─ 收缩阶段 (hold s)
     │    圆环从 0→100% 填充（绿色 #2ecc71）
     │    显示 "收缩并保持" + 剩余秒数
     │    语音 "收缩并保持"
     │
     └─ 放松阶段 (relax s)
          圆环从 100→0% 排空（蓝色 #3498db）
          显示 "放松" + 剩余秒数
          语音 "放松"

  完成
     显示 "训练完成！" + 语音 "训练完成，做得很好"
 ```

 ## UI 布局（移动端优先 375px 视口）

 ```
 ┌─────────────────────┐
 │   凯格尔训练          │  ← 标题
 │                      │
 │      ╭───────╮      │
 │      │ 数字   │      │  ← SVG 圆环 r=82, 线宽 8
 │      │ 阶段   │      │     中央：状态大字
 │      ╰───────╯      │     下方：小字阶段名
 │                      │
 │ 组数 1/10  剩余 3s   │  ← 信息栏（圆角背景）
 │                      │
 │ 收缩保持 [3]         │
 │ 放松时长 [3]         │  ← 设置面板
 │ 循环次数 [10]        │
 │                      │
 │ [开始训练] [停止]     │  ← 按钮组
 └─────────────────────┘
 ```

 ## 状态定义

 | 状态 | 圆环 | 中央文字 | 信息栏 |
 |---|---|---|---|
 | idle | 灰色静止 | "准备就绪" | — |
 | countdown | 橙黄色脉动：stroke-dashoffset 在 0 ↔ 0.3×周长 间往复一次/秒 | "3"→"2"→"1"→"开始！" | 占位符"—"，布局不跳动 |
 | hold | 绿色填充 | "收缩并保持" | 组号+剩余 |
 | relax | 蓝色排空 | "放松" | 组号+剩余 |
 | done | 绿色满环 | "训练完成！" | — |

 ## 圆环参数

 - 半径 82，线宽 8，周长 ~515.2
 - `stroke-linecap: round`
 - 动画过渡：`stroke-dashoffset` + CSS `transition`，时长等于阶段秒数

 ## 语音

 保持现有 Web Speech API 逻辑。在倒数阶段增加 "3、2、1、开始" 播报序列。
 阶段播报与现有一致（"收缩并保持"、"放松"、"训练完成，做得很好"）。

 ## 未包含 / 未来可扩展

 - 训练历史记录
 - 自定义语音包或音色选择器
 - 暂停功能
 - 振动反馈（移动端）
 - 圆环颜色自定义

 ## 设计原则

 - 所有动画使用 CSS transition，不引入 `requestAnimationFrame`
 - 不引入外部库（无框架、无动画库）
 - 保持 `index.html` 单文件结构
 - 状态机驱动 UI，避免回调嵌套过深
